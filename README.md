# 한칸
### 타이핑으로 작성하는 나만의 원고지

한칸은 원고지에 글을 쓰고, 글자 수를 확인하며 나만의 책을 만들어 가는 웹서비스입니다.

회원가입이나 로그인 없이 바로 시작할 수 있습니다. 키보드로 글을 입력하거나, 태블릿에서 펜슬로 손글씨를 쓸 수도 있습니다.

타이핑 시, 원고지 작성 양식에 맞게 글이 작성됩니다. 

## 한칸에서 할 수 있는 일

- **글자 수 확인** — 작성 중인 권의 글자 수를 실시간으로 확인합니다. 공백을 제외한 글자 수도 함께 표시합니다.
- **나만의 책장 만들기** — 최대 3권을 만들고, 한 권에 최대 12장까지 작성할 수 있습니다. 책장에는 직접 설정한 제목이 표시됩니다.
- **장마다 종이 선택** — 원고지, 백지, 모눈종이 중 원하는 형식을 선택합니다. 한 권 안에서도 장마다 다른 종이를 사용할 수 있습니다.
- **키보드와 손글씨 입력** — 타이핑한 글과 펜슬로 쓴 필기를 같은 종이에 담을 수 있습니다.
- **PDF 다운로드** — 현재 선택한 권의 모든 장을 하나의 PDF로 내려받습니다.
- **자동 저장과 백업** — 같은 기기·브라우저에서 이어 쓰고, 책장 전체를 백업 파일로 보관하거나 옮길 수 있습니다.

## ‘권’과 ‘장’은 어떻게 다른가요?

**권은 하나의 책, 장은 그 책에 들어가는 종이 한 페이지입니다.**

한 장은 **25칸 × 48줄, 총 1,200칸**으로 구성됩니다. 한 권에는 최대 12장이 들어가며, 최대 3권을 만들 수 있습니다.

1,200칸은 종이의 칸 수를 뜻합니다. 문단 들여쓰기나 숫자·영문 배치에 따라 실제 입력한 글자 수와 사용한 칸 수는 다를 수 있습니다.

## 이용방법

### 1. 책의 제목을 정해 주세요

종이 상단의 제목 입력란에 원하는 제목을 적습니다. 입력한 제목은 **나의 책장**에도 반영됩니다.

다른 글을 따로 쓰고 싶다면 **새 권 만들기**를 누르세요. 책장에서 제목을 선택하면 해당 권으로 이동합니다.

### 2. 종이 형식을 선택하세요

작성 화면 상단에서 현재 장의 종이 형식을 선택합니다.

| 종이 | 이런 글에 사용해 보세요 |
| --- | --- |
| 원고지 | 칸에 맞춰 쓰는 에세이, 소설, 글쓰기 연습 |
| 백지 | 자유로운 글과 메모, 손글씨 |
| 모눈종이 | 정리 노트, 도식, 간단한 스케치 |

종이 형식을 바꾸면 **현재 선택한 장에만 적용**됩니다.

### 3. 원하는 방식으로 글을 쓰세요

**키보드로 작성하기**

상단에서 **키보드**를 선택한 뒤 종이의 본문 영역을 눌러 입력합니다.

원고지에서는 Enter로 문단을 나누면 첫 칸을 자동으로 비웁니다. 숫자와 영문 소문자는 한 칸에 두 자씩 배치하며, 문장부호도 원고지 배치에 맞춰 표시합니다.

**손글씨로 작성하기**

상단에서 **손글씨**를 선택한 뒤 태블릿의 펜슬로 작성합니다.

펜 색상과 굵기를 조절할 수 있으며, **획 지우개**는 선택한 획 전체를 지웁니다. **손 터치 무시**를 켜면 손가락 입력을 막을 수 있고, 끄면 손가락으로도 쓸 수 있습니다.

글이나 필기를 수정할 때는 **되돌리기 / 다시 하기**를 사용할 수 있습니다.

### 4. 다음 장으로 이어 쓰세요

키보드 입력으로 한 장의 공간을 채우면 다음 장으로 이어집니다.

직접 새 페이지를 만들려면 **장 추가** 또는 **새 장**을 누르세요. **이전 장 / 다음 장** 버튼이나 장 선택 메뉴로 작성한 페이지를 오갈 수 있습니다.

### 5. 완성한 글을 PDF로 내려받으세요

내려받을 권을 책장에서 선택한 뒤 **PDF 다운로드**를 누릅니다.

해당 권의 모든 장이 A4 크기의 PDF로 저장됩니다. 제목, 본문, 손글씨, 장별 종이 형식이 함께 포함됩니다.

PDF는 화면의 배치를 이미지로 담은 파일이므로, PDF 안의 글을 텍스트로 선택하거나 검색할 수는 없습니다.

### 6. 책장을 백업하거나 다른 기기로 옮기세요

**책장 백업**을 누르면 모든 권의 제목, 글, 손글씨, 종이 형식이 담긴 JSON 파일이 내려받아집니다.

이어서 편집하거나 다른 기기로 옮기려면 한칸에서 **불러오기**를 누르고 해당 백업 파일을 선택하세요.

불러오기는 현재 책장을 백업 파일의 내용으로 교체합니다. 기존 글도 보관하려면 먼저 현재 책장을 백업해 주세요.

## 저장과 글자 수 안내

작성한 내용은 **현재 사용하는 기기·브라우저에 자동 저장**됩니다. 저장 상태가 **이 브라우저에 저장됨**으로 표시되는지 확인해 주세요.

다른 기기, 다른 브라우저, 다른 사이트 주소로는 자동 동기화되지 않습니다. 글을 옮길 때는 **책장 백업 → 불러오기**를 이용하고, 브라우저 데이터를 삭제하기 전에는 필요한 원고를 백업해 주세요.

글자 수는 본문에 입력한 글과 공백을 기준으로 계산합니다. **제목과 줄바꿈, 손글씨는 글자 수에 포함되지 않습니다.** 손글씨는 필기로 보관되며, 입력한 글자로 자동 변환되지 않습니다.

**읽고 공유할 때는 PDF를, 다시 편집하고 옮길 때는 책장 백업을 사용하세요.**
